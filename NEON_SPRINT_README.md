# NEON SPRINT (Godot 4.7.2)

Three-lane endless runner with neon graphics, obstacle dodging, jumps, slides, coins, powerups, skins and local save.

**Source project:** Download `NeonSprint_Godot_Project.zip`, unzip it and open `neon_sprint_godot/project.godot` with Godot 4.7.2.

**Windows executable:** When the [Windows build](../../actions/workflows/neon-sprint.yml) succeeds, get `NeonSprint.exe` from [Releases](../../releases/tag/neon-sprint-v1.0) or the Actions artifact.

Game controls: A / D = lanes; Space / W = jump; S / Down = slide; Esc = pause; M = sound.

Original game project; no third-party art or sounds.
